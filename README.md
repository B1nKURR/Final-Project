# Career Compass

Демонстрационный Telegram-бот для подбора профессий.

## Запуск

1. Установи Python 3.11.
2. Выполни:
   pip install -r requirements.txt
3. В config.py вставь токен от BotFather.
4. Запусти:
   python bot.py

SQLite-база career_compass.db создаётся автоматически.

В таблицу careers можно добавлять новые профессии.
